Come funziona

Tre passi, uguali per ogni tema.

Scegli tema e periodo

Apri il tema dal menu o dalle schede qui sopra, poi la sezione (es. Depositi, Occupazione) e l'anno o il trimestre.

Controlla i dati

Un riquadro verde dice che i dati automatici sono pronti. Per le imprese trascini i file di Stockview; la pagina controlla tutto e dice cosa manca.

Scarica le tabelle

Premi «Genera»: ottieni i file Excel con i nomi e le intestazioni dei modelli di Osserva, uno per uno o tutti insieme in un file ZIP.

Stato dei dati

Letto in questo momento dai controlli automatici. Se una fonte non risponde, le pagine permettono sempre di caricare i file a mano.
